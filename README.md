# Shrawani Bhor — Premium Portfolio

Dark, premium, responsive portfolio based on the supplied two-page resume.

## Add the photo later
The hero currently has a static framed photo placeholder. Replace the placeholder in `index.html` with an image and put the image in `assets/`, for example:

```html
<img src="assets/profile.jpg" alt="Shrawani Bhor">
```

## GitHub Pages
Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to a GitHub repository root. Then go to Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
